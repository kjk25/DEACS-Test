# Projektregeln

- Bei jedem Commit die Projektversion erhöhen. Standardmäßig die Patch-Version in `VERSION.txt` um eins erhöhen, sofern keine andere Versionsnummer vorgegeben ist.
- Die Versionsänderung gehört in denselben Commit wie die übrigen Änderungen. Vor dem Commit `python tools/build_usb_page.py` ausführen, damit die Oberfläche und die USB-Ausgabe die neue Version enthalten.
